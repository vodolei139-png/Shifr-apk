# Шифр

Простое Android-приложение для шифрования текста шифром Цезаря.
Написано на Python (Kivy), собирается в APK автоматически через GitHub Actions.

## Что умеет

- Шифрование и расшифровка текста сдвигом по русскому алфавиту (33 буквы, с «ё»);
- Сдвиг задаётся числом, направление — «ш» (зашифровать) или «р» (расшифровать);
- Буквы сохраняют регистр, знаки и цифры проходят без изменений;
- Алфавит замкнут в кольцо: «а» - 3 = «э».

## Как собрать

Сборка идёт сама: любой push в `main` запускает workflow
`.github/workflows/build.yml`, через ~15–20 минут готовый APK появляется
в артефактах запуска (папка `bin/`). Свежие версии — в разделе Releases.

Ручная сборка (если хочется):

    pip install buildozer cython
    buildozer -v android debug

Требуется Android SDK/NDK — buildozer скачает их сам при первом запуске.

## Технологии

- Python 3 + Kivy — интерфейс и логика;
- Buildozer / python-for-android — сборка APK;
- GitHub Actions — CI.

## Структура

- `main.py` — всё приложение;
- `buildozer.spec` — конфигурация сборки;
- `.github/workflows/build.yml` — автосборка.
