# Shifr 🔐

Простое приложение-шифратор для Android: шифр Цезаря, русский и латинский алфавиты.

## Возможности

- Шифрование и расшифрование кнопками — сдвиг от 1 до 33
- Пересчёт на лету при смене сдвига
- Открытие и сохранение текстовых файлов (UTF-8)
- Поделиться результатом в любое приложение

## Установка

1. Скачайте APK из раздела Releases
2. Разрешите установку из неизвестных источников
3. Готово — шифруйте!

## Сборка

Проект собирается автоматически: коммит → Actions → Releases.
