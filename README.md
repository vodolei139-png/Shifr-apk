# Shifr

Простой шифратор текста с интерфейсом в стиле дощатого кабинета.

Shifr шифрует и расшифровывает текст шифром Цезаря: каждая буква
сдвигается по алфавиту на заданное число позиций. Русский и латинский
алфавиты шифруются по отдельности, остальные символы остаются как есть.

## Возможности

- Зашифровать / расшифровать текст шифром Цезаря
- Настройка сдвига от 1 до 33 кнопками «+» и «−»
- Открытие текстового файла с устройства
- Сохранение результата в файл
- Отправка результата через любой мессенджер или почту («Поделиться»)
- Дощатая тема оформления: деревянные доски, сучки, салатовые кнопки
- Понятный экран ошибки вместо молчаливого вылета

## Как пользоваться

1. Введите текст в поле.
2. Кнопками «+» и «−» выберите сдвиг (по умолчанию 3).
3. Нажмите «Зашифровать» — результат появится внизу.
4. «Расшифровать» возвращает текст обратно при том же сдвиге.
5. Результат можно сохранить в файл или отправить друзьям.

Чтобы расшифровать сообщение, получатель должен знать сдвиг —
это и есть секретный ключ переписки.

## Как собрать APK

Сборка идёт автоматически на GitHub Actions:

- при каждом пуше в `main` запускается «Build APK (Native Ubuntu)»;
- Buildozer собирает APK (Kivy + python-for-android, arm64-v8a);
- APK подписывается ключом `shifr-release.keystore` из репозитория;
- готовый файл появляется на вкладке Releases.

Готовые APK: вкладка Releases репозитория.
